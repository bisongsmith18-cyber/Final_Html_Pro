## Final HTML/CSS Project 1.0

##  Overview

This project is a **pixel-perfect HTML & CSS implementation** of a provided Figma design. The goal is to replicate the UI as closely as possible using **only semantic HTML and raw CSS**, without JavaScript (unless explicitly instructed).

This project focuses on:

* Clean and semantic HTML structure
* Accurate layout, spacing, and typography
* Responsive design principles
* Professional file organization

##  Requirements

### 1. HTML Structure

* Use **semantic HTML5 elements** (`header`, `main`, `section`, `article`, `footer`, etc.)
* Structure must closely follow the Figma layout
* All images must include meaningful `alt` attributes

### 2. CSS Styling

* Replicate **font sizes, colors, spacing, margins, paddings, and layout** from the design
* Use **Flexbox and/or CSS Grid** for layouts
* No frameworks (Bootstrap, Tailwind, etc.)
* Use raw CSS only
* Use CSS custom properties (e.g. `--main-color`) where appropriate
* A CSS reset or normalize file may be used if needed

### 3. Assets

* Export images and icons from Figma (PNG/SVG)
* Store all assets in `/assets` or `/images`
* Reference assets correctly in HTML

### 4. Typography

* Use **Google Fonts** if the design requires custom fonts
* Match:

  * Font family
  * Font weight
  * Line height
  * Letter spacing

### 5. Responsiveness

* Design must work on:

  * Mobile
  * Tablet
  * Desktop
* Use **media queries** to adjust layout
* Follow a **mobile-first approach**

### 6. File Organization

* Keep files clean and organized
* Use consistent and readable naming conventions
